# Правила проекта

## Контекст

- Проект представляет собой fullstack-приложение в монорепозитории.
- Используемый стек: React, TypeScript, NestJS, Prisma, PostgreSQL и GraphQL.

## Структура проекта

- Структура монорепозитория пока не определена.
- Начальную структуру проекта пользователь создаёт вручную.
- Не создавать и не изменять структуру проекта без явного запроса пользователя.
- Не предполагать расположение приложений, пакетов и конфигурационных файлов до их появления в репозитории.
- Перед предложением структурных или архитектурных изменений изучать текущее состояние проекта.

## Технические решения

- Не выбирать менеджер пакетов, инструмент управления монорепозиторием и дополнительные библиотеки без согласования.
- Не фиксировать архитектурные решения, которые пользователь ещё не принял.
- Не добавлять зависимости без объяснения их назначения и согласования.
- Не сохранять в репозитории секреты и реальные значения переменных окружения.
